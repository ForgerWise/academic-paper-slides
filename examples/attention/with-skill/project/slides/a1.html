Figure: Vaswani et al., NIPS 2017, Fig. 1, Sec. 3.1; orange box added by presenter

[≤ 4:42] Part A is the two stacks. The orange box marks the encoder, which reads the input sentence. The encoder is a stack of six identical layers. Each layer has two parts. The first part is self-attention, where every input word looks at every other input word. The second part is a small feed-forward network, which is applied to each word position separately. Around each part there is a residual connection, followed by layer normalization. The last layer gives one vector per input word, and the decoder will read these vectors.
