Source: Vaswani et al., NIPS 2017, Sec. 3.1; diagram redrawn by presenter from Fig. 1

[≤ 4:48] We start with the two stacks. The encoder reads the input sentence, and the diagram shows one of its layers from top to bottom. The encoder is a stack of six identical layers. Each layer has two parts. The first part is self-attention, where every input word looks at every other input word. The second part is a small feed-forward network, which is applied to each word position separately. Around each part there is a residual connection, followed by layer normalization. The last layer gives one vector per input word, and the decoder will read these vectors.
