[≤ 8:35] Now the last part. One thing is still missing. Attention treats the sentence as a set, so the model has no idea about word order. The authors fix this at the input, as the diagram shows. They add a position vector to every word embedding. The position vector is built from sine and cosine waves with many different frequencies. Why waves and not a learned table? With waves, a shift by a fixed number of words is a linear function of the encoding, so relative positions should be easy to learn. And waves may also work for sentences longer than any sentence in the training data.
