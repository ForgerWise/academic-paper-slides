[≤ 7:33] We are still on attention. One attention function gives one set of weights for each word. The authors found that this is not enough, so they run eight attention layers side by side. Each one is called a head. Every head first projects the queries, keys and values into a smaller space of sixty-four dimensions, with its own learned weights. Then it runs the attention you just saw. At the end the outputs of all heads are joined and projected once more. Why does this help? Different heads can look at different things. A single head has to average everything into one set of weights. And because each head is small, the total cost is about the same as one large head.
