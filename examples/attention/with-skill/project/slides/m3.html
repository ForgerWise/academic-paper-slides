Multi-Head Attention

  • Multi-head attention: 8 attention layers (heads) in parallel
  • Each head projects Q, K, V to 64 dimensions with its own weights
  • Head outputs are concatenated and projected once more
  • Why several heads
  • Heads attend to different positions; a single head averages them
  • Total cost is close to one full-size head

Figure: Vaswani et al., NIPS 2017, Fig. 2 (right), Sec. 3.2.2

[≤ 7:22] Still in part B. One attention function gives one set of weights for each word. The authors found that this is not enough, so they run eight attention layers side by side. Each one is called a head. Every head first projects the queries, keys and values into a smaller space of sixty-four dimensions, with its own learned weights. Then it runs the attention you just saw. At the end the outputs of all heads are joined and projected once more. Why does this help? Different heads can look at different things. A single head has to average everything into one set of weights. And because each head is small, the total cost is about the same as one large head.
