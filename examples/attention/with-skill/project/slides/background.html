Background

  • Machine translation uses an encoder and a decoder
  • Encoder: turns the input sentence into vectors
  • Decoder: writes the output one word at a time
  • In 2017 the best models are recurrent networks
  • Attention is added so the decoder can look at any input word
  • It is used only together with recurrence

Source: Vaswani et al., NIPS 2017, Sec. 1 and 3

[≤ 0:25] Let me start with the background. Machine translation turns a sentence in one language into a sentence in another. In 2017 this was done with an encoder and a decoder. The encoder reads the input sentence and turns it into a list of vectors. The decoder then writes the translation one word at a time, and each step uses the words it has already written. Both parts were recurrent networks. The best systems also added attention, which lets the decoder look back at any word of the input. So attention already existed, but only as a helper for the recurrent network.
