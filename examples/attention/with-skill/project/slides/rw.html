[≤ 3:42] This table compares three kinds of layers, and it comes from the paper. Look at the last two columns first. The third column is how many steps must run one after another. A recurrent layer needs one step per word. Convolution and self-attention need only one step, so they can run in parallel. The last column is the longest path between two words. For a recurrent layer the path grows with the sentence length. For convolution it grows more slowly. For self-attention it is always one, because every word connects directly to every other word. The price is in the second column. Self-attention costs more when sentences are very long.
