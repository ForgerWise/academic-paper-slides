[≤ 2:07] To follow the method you need one concept, and that is attention. Think of attention as a lookup, like the one in the diagram. Take the sentence, the cat sat on the mat because it was tired. The query is the word it. Every other word is a key with a value. For every key the model computes a score, how well it matches the query. Here cat gets the highest score. A softmax turns the scores into weights that add up to one. So cat gets 0.67. The output is the weighted sum of the values, so it is mostly made of cat. When the queries, keys and values all come from the same sentence, as they do here, this is called self-attention.
