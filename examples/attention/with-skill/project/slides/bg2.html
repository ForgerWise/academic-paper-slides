Background 2

  • Attention: answer a query from key–value pairs
  • Weight: how well the query matches each key
  • Output: the weighted sum of the values
  • Self-attention: queries, keys and values come from the same sentence
  • Every word looks at every other word

Source: Vaswani et al., NIPS 2017, Sec. 2 and 3.2

[≤ 2:06] The second piece of background is attention. Think of attention as a lookup. You have a query, and you have a set of keys, each with a value. For every key the model computes how well it matches the query. That gives a weight. The output is the sum of all values, each multiplied by its weight. So the output is mostly made of the values whose keys match best. Self-attention is the special case where the queries, keys and values all come from the same sentence. Every word asks every other word the same question. Which of you matters to me?
