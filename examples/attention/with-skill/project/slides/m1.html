Method 1

  • Encoder (left) and decoder (right): 6 identical layers each
  • Encoder layer: self-attention, then a feed-forward network
  • Decoder layer adds attention over the encoder output
  • Around every sub-layer
  • Residual connection, then layer normalization
  • Decoder self-attention is masked
  • A position sees only earlier output positions

Figure: Vaswani et al., NIPS 2017, Fig. 1, Sec. 3.1

[≤ 4:38] Now the model itself. The figure shows the whole Transformer. The left block is the encoder and the right block is the decoder. Each block is repeated six times. One encoder layer has two parts. First comes self-attention, where every input word looks at every other input word. Then comes a small feed-forward network. The decoder layer has one extra part in the middle. It attends over the output of the encoder, and this is how the decoder reads the input sentence. Around every part there is a residual connection and layer normalization. One more detail. Self-attention in the decoder is masked, so a word can only look at the words before it.
