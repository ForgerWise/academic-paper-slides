Parsing results

  • Tests a different task: English constituency parsing (WSJ section 23, F1 score)
  • Result
  • WSJ data only: 91.3 (best earlier result 91.7)
  • Semi-supervised: 92.7 (best earlier result 92.1)
  • A 4-layer Transformer, almost unchanged from the translation model

Source: Vaswani et al., NIPS 2017, Table 4, Sec. 6.3

[≤ 12:30] Does the model only work for translation? The authors tested a very different task, English constituency parsing. Here the output is a tree structure and it is much longer than the input. They used a Transformer with four layers and did very little tuning. Trained only on the Wall Street Journal data, it reaches an F1 score of 91.3. With extra semi-supervised data it reaches 92.7, above the earlier semi-supervised results. So the architecture carries over to another task.
