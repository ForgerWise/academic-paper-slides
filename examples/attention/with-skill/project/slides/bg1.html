Background 1

  • Translation models have an encoder and a decoder
  • The Transformer keeps this structure and changes what is inside
  • Encoder: turns the input sentence into vectors
  • One vector for each input word
  • Decoder: writes the output one word at a time
  • Each step uses the words written so far (auto-regressive)

Source: Vaswani et al., NIPS 2017, Sec. 3

[≤ 1:19] Before the method, two pieces of background. The first is the encoder and decoder structure, which almost every translation model uses. The encoder reads the input sentence and turns it into a list of vectors, one vector for each input word. The decoder then writes the translation one word at a time. At every step it looks at the encoder vectors and at the words it has already written. This is called auto-regressive generation. The Transformer keeps this overall structure. What changes is what happens inside the encoder and the decoder.
